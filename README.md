# TheoryTestApp – public pages

Public policy pages for the Android app **הדרך ל־26** (Hebrew driving-theory exam prep). This repository contains only these static pages; the app code lives in a separate private repository.

- Privacy policy: `privacy/` (Hebrew), `en/privacy/` (English)
- Terms of use: `terms/`, `en/terms/`
- Support and contact: `support/`, `en/support/`

Published with GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root): `https://erankopel.github.io/TheoryTestAppPublicPages/`. The privacy-policy URL for the Play Console is `https://erankopel.github.io/TheoryTestAppPublicPages/privacy/`.

The pages are plain HTML and CSS with no scripts, cookies, analytics or external requests. The texts are templates written for this app and should be reviewed by a lawyer before the app is sold.
